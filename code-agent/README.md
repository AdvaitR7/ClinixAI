# code-agent

Working plans for coding agents. They are temporary.

- Put a plan for in-flight work in `c-plans/` as `YYYY-MM-DD-<topic>.md`.
- When the work is merged, distill what you decided (what, why, when, where) into [`docs/history.md`](../docs/history.md), and any remaining gaps into [`docs/status.md`](../docs/status.md). Then delete the plan.
- Keep plans to markdown only. Screenshots and design dumps don't belong here.

The project documentation starts at [`docs/README.md`](../docs/README.md).
