# Security policy

CliniX AI is a prototype for synthetic-data evaluation. Do not upload real patient data or use it for clinical care.

## Reporting a vulnerability

Use **Security → Advisories → Report a vulnerability** on GitHub if private reporting is available. Otherwise, contact a maintainer privately to arrange a secure channel. Do not open a public issue for a vulnerability.

Include the affected commit or version, a description of the impact, and evidence from an instance you control using synthetic data. Redact credentials, patient information and sensitive deployment details. Do not test systems you do not own or have permission to test.

Maintainers should [enable GitHub private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository) when the repository becomes public.
